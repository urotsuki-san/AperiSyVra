# Security Policy

AperiSyVra P1 is research software and has no assigned security level.

Use a private GitHub security advisory for implementation flaws, key-recovery results, structural attacks, or decoder side channels. Include the affected commit, a minimal reproducer, and the measured attack cost when available.

Public issues are suitable for build failures, documentation corrections, and already-public analysis.

Do not attach private keys, confidential plaintext, or production credentials to a report.
